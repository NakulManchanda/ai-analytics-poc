# 0097 — #171 eval foundations (offline slice)

## Goal
Add `tooling/evals/`: versioned golden dataset, deterministic taxi graders, DeepEval metric setup with
opt-in judge calls, run manifest, baseline-vs-candidate delta reports with regression thresholds, docs.

## Starting point
main at e72fc55. The capture schema (`capture.v1`) is owned by the parallel #169 track; this PR
consumes the contract in synthetic fixtures and does not touch `services/app/`.

## Decisions
- Separate uv project mirroring `tooling/benchmarks/`; DuckDB and DeepEval are optional extras.
- Reference facts come from hand-authored SQL run on the pinned parquet (`evals refresh-reference`);
  a test re-runs the SQL when the parquet is available to catch drift.
- CI runs on synthetic `capture.v1` fixtures and recorded judge verdicts; live judging requires
  `EVALS_LIVE_JUDGE=1`. Fixtures are generated by `evals.synth` and a test fails if they drift.
- 37 cases (14 deterministic, 8 ReAct, 5 multi-turn, 6 unsupported, 4 failure), all marked
  `pending_human_review`.
